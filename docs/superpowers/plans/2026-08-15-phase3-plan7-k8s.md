# Phase 3 · 计划 25：K8s 安装器（M2.5 私有化扩展）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 K8s 安装器（M2.5/TechDesign onprem/：Compose 起步 → K8s）：生产 Kubernetes 清单（Deployment/Service/ConfigMap/Secret/PVC + ingress）+ 一键安装脚本（`kubectl apply` + 健康检查）。与已有 Docker Compose 安装器（计划 18）互补，供高可用场景。

**Architecture:** `deploy/k8s/` 目录：`namespace.yaml`（ta-prod）、`configmap.yaml`（非敏感配置）、`secret.yaml`（JWT_SECRET/密码/API Key，用 base64 占位 + 安装时替换）、`postgres.yaml`（StatefulSet + PVC + Service）、`minio.yaml`（Deployment + PVC + Service）、`gateway.yaml`（Deployment + ConfigMap env + Service + 迁移 initContainer）、`web.yaml`（Deployment + Service）、`ingress.yaml`、`install.sh`（校验 kubectl → 生成 secret（从 env 或提示）→ apply → 健康检查）。镜像复用计划 18 的 Dockerfile（deploy/prod/Dockerfile.web/gateway——需推到 registry，install.sh 提示镜像配置）。

**Tech Stack:** Kubernetes 清单（Deployment/StatefulSet/Service/ConfigMap/Secret/PVC/Ingress）+ bash install.sh。无代码改动。

**质量审查决策（T1-T2 后追加）：** ① minio Deployment 补独立 PVC volumes（Deployment 不支持 volumeClaimTemplates——计划注授权修正）；② `REPLACE_IMAGE_PREFIX`/`REPLACE_HOST` 占位由 install.sh sed 替换（K8s 清单不支持 env 变量插值）；③ `$(POSTGRES_PASSWORD)` 引用 envFrom secret（kubelet 先处理 envFrom 再展开 env，官方语义 ✓）；④ install.sh b64 加 `tr -d '\n'`（GNU/BSD base64 默认 76 列折行会破坏单行 YAML）。**记录后续**：无集群实测（静态校验；kubectl apply 实测记集群环境）；镜像推送 registry（install.sh 提示 IMAGE_PREFIX）；多副本 DB/MinIO 高可用、监控、自动扩缩记后续。

**决策记录：** K8s 安装器为「清单 + 脚本」交付（无集群环境实测——本地无 K8s，语法用 `kubectl --dry-run=client -f` 校验或 yaml 解析器校验，实测记后续）；镜像复用计划 18 Dockerfile（未推送 registry——install.sh 用 `IMAGE_PREFIX` env 配置镜像地址，默认 `localhost:5000/ta-` 提示推送到私有 registry）；Secret 用 base64 占位（安装脚本从 env 或 prompt 生成真实值替换——不落库明文）；gateway 迁移用 initContainer（node lib/migrate.js 先跑）或 Job——用 initContainer（镜像含迁移产物）；minio/postgres 用 StatefulSet + PVC（数据持久化）；ingress 供外部访问（host 可配置）；不包含 Redis/监控（当前架构无 Redis，Prometheus 记后续）；K8s 清单正确性用 `kubectl kustomize` 或 yaml 解析验证（本地无集群则静态校验 + 记录）。

> 注：`${IMAGE_PREFIX}` 是 K8s 清单不支持的变量——**修正**：清单内用固定占位 `REPLACE_IMAGE_PREFIX`，install.sh 用 sed 替换为实际前缀（默认 `localhost:5000/ta-`）；`$(POSTGRES_PASSWORD)` 依赖 envFrom 的 secret env（K8s 支持 envFrom + env 组合展开——`$(VAR)` 引用 envFrom 注入的变量 ✓）。DATABASE_URL 含密码需注意 secret 展开——实现时核对 K8s `$(VAR)` 语法对 envFrom 的支持（支持：env 的 value 中 $(VAR) 引用同容器其他 env 或 envFrom）。

- [x] **Step 4: install.sh**

创建 `deploy/k8s/install.sh`：

```bash
#!/usr/bin/env bash
# Turing Agent K8s 一键安装器（M2.5 K8s 扩展）
set -euo pipefail
DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
cd "$DIR"

echo "=== Turing Agent K8s 安装器 ==="
command -v kubectl >/dev/null 2>&1 || { echo "❌ 需要 kubectl"; exit 1; }
kubectl cluster-info >/dev/null 2>&1 || { echo "❌ 无法连接集群（kubectl cluster-info 失败）"; exit 1; }

# 配置
IMAGE_PREFIX="${IMAGE_PREFIX:-localhost:5000/ta-}"
HOST="${TA_HOST:-ta.example.com}"
JWT_SECRET="${JWT_SECRET:-$(openssl rand -hex 32)}"
POSTGRES_PASSWORD="${POSTGRES_PASSWORD:-$(openssl rand -hex 16)}"
MINIO_ROOT_PASSWORD="${MINIO_ROOT_PASSWORD:-$(openssl rand -hex 16)}"
MODEL_API_KEY="${MODEL_API_KEY:?MODEL_API_KEY 必填（模型 API Key）}"

[ "${#JWT_SECRET}" -ge 32 ] || { echo "❌ JWT_SECRET 需 ≥32 字符"; exit 1; }

echo "✅ 配置校验通过（镜像前缀: $IMAGE_PREFIX，host: $HOST）"

# 生成 secret（base64）
b64() { printf '%s' "$1" | base64; }
sed -e "s|REPLACE_ME_JWT_SECRET|$(b64 "$JWT_SECRET")|" \
    -e "s|REPLACE_ME_PG_PASSWORD|$(b64 "$POSTGRES_PASSWORD")|" \
    -e "s|REPLACE_ME_MINIO_PASSWORD|$(b64 "$MINIO_ROOT_PASSWORD")|" \
    -e "s|REPLACE_ME_MODEL_API_KEY|$(b64 "$MODEL_API_KEY")|" \
    secret.yaml | kubectl apply -f - >/dev/null

echo "✅ secret 已应用"

# 应用清单（替换镜像前缀与 host）
for f in namespace.yaml configmap.yaml postgres.yaml minio.yaml gateway.yaml web.yaml ingress.yaml; do
  sed -e "s|REPLACE_IMAGE_PREFIX|$IMAGE_PREFIX|g" -e "s|REPLACE_HOST|$HOST|g" "$f" | kubectl apply -f - >/dev/null
  echo "  应用 $f"
done

echo "⏳ 等待就绪（最长 120s）..."
kubectl -n ta-prod wait --for=condition=available --timeout=120s deployment/ta-web deployment/ta-gateway
kubectl -n ta-prod rollout status --timeout=120s statefulset/ta-postgres || true

echo ""
echo "=== 安装完成 ==="
echo "访问：http://$HOST（Ingress）"
echo "MinIO 控制台：kubectl -n ta-prod port-forward svc/minio 9001:9001"
echo "数据：PVC ta-pgdata / ta-minio-data（10Gi）"
echo "提示：镜像需已推送到 $IMAGE_PREFIX（docker build 见 deploy/prod/Dockerfile.*）"
```
