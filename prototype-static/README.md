# Turing Agent 桌面端交互原型（极简白）

PRD（`../TuringAgent.md`）与技术方案（`../TechDesign.md`）的桌面端交互原型。零依赖静态实现，浏览器直接打开即可体验，无需构建。

## 打开方式

```bash
open index.html        # macOS
start index.html       # Windows
```

首次打开会进入登录页（`login.html`），点「快速体验（演示登录）」即可。

- `login.html` — **登录页**（极简白，yanse.md §8.1）：表单登录 / 快速体验 / 企业 SSO 演示
- `index.html` — **主工作台**：顶栏 + 左侧边栏（消息/项目/联系人/智能体）+ 中间消息流 + 右侧上下文面板 + 待办中心
- `board.html` — **任务看板**：统计瓦片 + 五列看板（人类与智能体混合任务）+ 筛选 + 新建任务 + 拖拽 + 任务详情 + 多级审批
- `org.html` — **组织与治理**（个人菜单 → 组织与治理）：成员与部门 / 角色权限矩阵 / 智能体配额与熔断 / 审计日志（筛选、导出 CSV）

> 各页通过 `localStorage`（前缀 `ta.`）共享同一份状态：在工作台确认审批，看板同步流转；在看板通过审批，回到工作台卡片与进度视图立即一致（同一状态的两个渲染，对应 TechDesign §4.3）；审批、任务、文档编辑等关键操作实时写入审计日志，可在组织治理页检索导出。

## 设计方向：Apple 体系（open-design / design-systems/apple）

| 设计决策 | 说明 |
|----------|------|
| 中性三基色：绝对黑 `#000000` · 淡苹果灰 `#f5f5f7` · 纯白 `#ffffff` | 结构由色调对比分层，不做装饰性渐变 |
| **Apple 蓝 `#0071e3` 是唯一动作色** | 主动作/链接/选中条/聚焦环/进度条/发送按钮，全部蓝色表达（链接 `#0066cc`，暗景 `#2997ff`） |
| SF Pro Display（标题紧凑负字距）+ SF Pro Text（正文/控件），回退 Inter | 排版是稳定器：标题像机械般精密，正文保持零售级可读密度 |
| 胶囊几何（980px 圆角） | 按钮/开关/搜索/项目切换器都是胶囊形，Apple 签名动作语言 |
| 自己消息 = **iMessage 蓝气泡**；智能体 = 淡灰 `#f5f5f7`；人类 = 白底细描边 | 气泡体系呼应 iOS 信息，一眼区分来源 |
| 智能体 = 石墨黑 `#272729` 圆角方块头像 + 灰底「AI」标 | 呼应 PRD FR-CHAT-03 |
| 语义色 = Apple 系统色 | 未读徽标红 `#ff3b30` · 警告橙 `#ff9500` · 成功绿 `#34c759`（在线点/开关） |
| 克制阴影（0.06–0.12 透明度）+ 玻璃工具栏 | 深度只用于拾高模块；顶栏毛玻璃（backdrop blur 20px） |
| 等宽字体用于时间戳/ID/审批流编号 | 元信息弱化，呼应 IM 工作台定位 |

## 可体验的交互清单

**主工作台（index.html）**

1. **多级审批卡片**（FR-APP-02）：
   - 「设计稿评审」= 单级会签（2 人确认后通过）；「上线审批」= **两级串行**（技术审批 → 业务审批，逐级推进）
   - 确认 → 卡片状态/系统消息/**右侧面板「设计评审」里程碑联动**/看板任务流转（跨页持久）；驳回/修改意见 → 内联原因；**转办** → 把待审批人改派给其他人（留痕）
2. **待办中心**（FR-APP-04，顶栏 ✓ 图标带角标）：跨会话聚合所有审批卡，支持**逐条处理 / 全部确认**（串行卡按级推进），并列出**逾期任务提醒**
3. **群内 @分配任务**（FR-TASK-01）：发送「@Ta-Fullstack 负责 支付网关对接」→ 看板自动出现任务 + Ta-PMO 回报
4. 切换左侧会话：报销系统项目群 / 审批群（需求变更卡片）/ 财务-IT 协作群（**静默策略**）/ Ta-PMO 日报
5. 联系人私聊（离线成员不回复）；项目群切换与 `Ctrl+N` 新建项目群（Ta-PM 自动接入，刷新后仍在）；智能体 Tab 点击自动 @
6. 发消息 → 「正在输入」→ 回复；**页面失焦时智能体回复触发系统通知**（FR-DESK-03，授权后走 Notification API）
7. 消息操作：复制 / 引用（可取消）；输入区：表情选择器 / 文件发送 / **拖拽文件或图片到输入框直接发送**（FR-DESK-02）/ **粘贴截图** / 语音输入 / `Ctrl+Shift+A` @提及选择器
8. 右侧面板：进度 / 看板（迷你）/ **记忆文档可编辑，保存生成新版本并留痕**（FR-MEM-02，版本历史可查）/ **交付物按 全部/图片/文档 筛选**（FR-CHAT-08，含自己上传的文件）
9. **日报**（FR-TASK-03）：登录后每日自动推送（带系统通知）；PMO 会话头部菜单可手动「生成今日日报」（数据来自看板实时计算）
10. 顶栏：通知中心 / 项目切换 / 设置（通知开关/日报时间/重置演示数据）/ 个人菜单（在线状态、**组织与治理入口**、退出登录回登录页）
11. 会话头部菜单：群内搜索 / 查看审批流 / 静音通知 / 标记全部已读
12. 快捷键：`Ctrl+Enter` 发送 · `Ctrl+Shift+A` @智能体 · `Ctrl+F` 全局搜索 · `Ctrl+N` 新建项目群 · `Esc` 关闭弹层

**任务看板（board.html）**

1. 筛选：全部 / 我的 / AI 任务 / 待审批 / 逾期（空列自动提示）
2. 「＋ 新建任务」→ 名称 / 执行者（人类或智能体）/ 优先级 / 截止日期 → 进入「待开始」列
3. **点击任务卡 → 详情弹窗**：移动状态（五列即点即走）/ 改执行者、优先级、截止日期 / 阻塞原因 / 删除（二次确认）
4. **拖拽卡片**跨列流转（列高亮提示）
5. **审批列卡片可直接确认/驳回**（走同一审批状态机：串行卡按级推进，全部通过后任务自动进入「已完成」）→ 与工作台实时同步
6. 统计瓦片实时计算：本周完结 / 进行中 / 阻塞 / 待审批 / AI 产能占比（黑色品牌瓦片）

**组织与治理（org.html）**

1. **成员与部门**：部门树筛选 / 邀请成员（姓名、邮箱、部门、角色）/ 角色下拉变更（即时生效 + 审计）
2. **角色权限**：PRD 5.1.1 权限矩阵（企业管理员 → 只读成员）
3. **智能体管理**（FR-ORG-04）：模型切换（多供应商/国产可插拔）、Token 配额条、启停开关、**模拟超额触发熔断**（系统通知 + 审计留痕）
4. **审计日志**（FR-PERM-03）：审批/任务/权限/智能体/系统全量留痕，按类型筛选，**导出真实 CSV 文件**；工作台与看板的操作实时写入

## 说明

- 纯演示原型：数据为内存合成（报销系统需求澄清 → 设计评审 → 变更/上线审批场景），无网络请求、无外部依赖；用户操作经 `ta.*` 键持久化到 localStorage，「设置 → 重置演示数据」可一键还原（保留登录态）。
- 登录门禁：无 `ta.session` 时工作台/看板/组织页自动跳转登录页；「退出登录」清除会话。
- 响应式：≤1280px 隐藏右侧面板（顶栏面板开关可强制展开）；≤880px 侧边栏收窄为图标栏。
- 无障碍：语义化标签、`role="tablist"`、`role="switch"`、焦点环（黑色）、`aria-live` toast、`prefers-reduced-motion` 降级。
- 动效仅使用 `transform / opacity`（合成器友好），符合性能规范。
